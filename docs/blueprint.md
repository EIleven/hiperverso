# **App Name**: Echo

## Core Features:

- Twitz Feed: Display an infinite, refreshing list of short posts (twitz), including carousels.
- Post Creation/Edition: Enable users to create and edit text, image, and video posts.
- Interactions: Allow users to 'like', comment, and repost posts, with real-time updates.
- User Profile: Display and allow editing of user profiles with bio and avatar.
- Trending Topics: Generate post suggestions and trending topics based on current user activity, acting as a tool to generate engaging content ideas.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) to evoke modernity.
- Background color: Dark gray (#2B2B2B) for a modern and sophisticated feel.
- Accent color: Soft purple (#BE95C4) to provide a pleasant, subtle contrast and guide user focus.
- Clean, sans-serif fonts to ensure maximum readability on both Android and iOS.
- Simple and consistent icons to enhance usability across all modules.
- Subtle animations and transitions to provide feedback during interactions.
